# DeskWidget

一个使用 Python 与 PySide6 开发的 Windows 桌面组件工具。它把图片、便签、今日计划、一周日程、番茄钟和倒数日放到桌面上，同时提供任务管理、课表导入和周/月/年日历视图。

DeskWidget 以轻量、可定制和本地优先为目标：组件状态与计划数据均保存在本地，不依赖在线账户。

## 功能

### 桌面组件

- **图片组件**：展示课表、日程或参考图片，支持拖动、滚轮缩放、更换和复制。
- **便签**：自由编辑、自动保存，支持多种便签颜色。
- **今日计划**：在桌面查看待办、截止状态并直接完成任务。
- **一周日程**：在桌面小时级七天时间轴中查看课程和任务、切换周次，并可收成一行以节省空间。
- **番茄钟**：开始、暂停、继续和重置，可绑定任务并记录专注次数。
- **倒数日与纪念日**：未来事件显示“距离事件还有 X 天”，过去事件显示“事件已经 X 天”，并实时更新精确时间。

所有组件均支持：

- 拖动位置
- 从边缘或四角调整大小
- 窗口置顶
- 单独隐藏与托盘恢复
- 在任意区域右键打开组件菜单
- 自动保存位置、尺寸和配置

### 计划中心

- 快速新增任务
- 设置截止日期和时间
- 今天、即将到期、全部、已完成筛选
- 编辑、完成和删除任务
- 周、月、年三种日历视图；周视图使用精确到小时的七天时间轴
- 在日期卡片中直接查看任务
- 番茄专注次数统计

### 课表

- 独立课表管理页面
- 从 iCalendar（`.ics`）或 CSV 文件批量导入课程
- 手动新建、编辑或删除课程，支持双击课程快速编辑
- 支持课程、星期、上下课时间、地点、教师和学期起止日期
- 在周/月/年日历中通过“显示课表”开关叠加或隐藏课程；周视图按实际上下课时间绘制课程块
- 课表开关和课程数据均保存在本地

学校教务系统或日历软件导出的 `.ics` 文件可以直接导入。程序会合并相同课程时段，同时保留文件中实际存在的上课日期，不会自动补上停课周。

CSV 至少需要包含 `课程`、`星期`、`开始时间`、`结束时间` 四列，可选列为 `地点`、`教师`、`开始日期`、`结束日期`。星期可填写“周一”至“周日”或数字 `1` 至 `7`，日期格式为 `YYYY-MM-DD`。

```csv
课程,星期,开始时间,结束时间,地点,教师,开始日期,结束日期
高等数学,周一,08:00,09:40,A101,张老师,2026-09-01,2027-01-15
```

### 个性化

- 靛蓝、海蓝、青绿、暖橙、玫红和浅叶绿主题
- 桌面组件半透明毛玻璃效果
- 可调节组件背景透明度
- 主界面、文字和图片组件保持清晰不透明

### 系统托盘

- 单击或双击托盘图标打开主界面
- 恢复全部组件
- 隐藏全部组件
- 完全退出程序

## 环境要求

- Windows 10/11
- Python 3.10 或更高版本
- PySide6

毛玻璃效果使用 Windows 原生窗口合成接口；其他核心功能不依赖该效果。

## 安装

克隆项目：

```powershell
git clone https://github.com/jielanjiang46-dotcom/DeskWidget.git
cd DeskWidget
```

建议创建虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

安装依赖：

```powershell
python -m pip install PySide6
```

## 运行

直接运行：

```powershell
python main.py
```

项目也包含 `启动桌面组件.bat`。该脚本目前指向开发者本机的 Conda 环境：

```bat
D:\anaconda3\envs\deskwidget\pythonw.exe
```

如果希望双击批处理启动，请将其中的 Python 路径修改为你本机的 `pythonw.exe`，例如：

```bat
@echo off
start "" "%~dp0.venv\Scripts\pythonw.exe" "%~dp0main.py"
```

## 使用方法

1. 启动后，在主界面的“组件”页面选择要添加的桌面组件。
2. 拖动组件可调整位置；拖动边缘或四角可调整尺寸。
3. 在组件任意区域右键，可打开管理菜单。
4. 关闭主界面不会退出程序，可从系统托盘重新打开。
5. 如需彻底退出，请使用托盘菜单中的“退出全部”。

任务可以在“任务”页面管理，并会同步到桌面今日计划组件和日历视图。番茄钟、倒数日与纪念日既可以在主界面集中查看，也可以作为独立桌面组件使用。

## 本地数据

程序会在项目目录下生成以下文件：

| 文件 | 内容 |
| --- | --- |
| `widgets.json` | 组件类型、位置、尺寸和状态 |
| `plans.json` | 任务、截止时间、完成状态和专注次数 |
| `courses.json` | 导入的课表和日历课表显示开关 |
| `settings.json` | 主题、毛玻璃开关和背景透明度 |

这些运行时文件已被 `.gitignore` 排除，不会默认提交到仓库。用户添加到 `assets/` 的图片同样不会被提交。

## 扩展新组件

新增组件时，可以继承 `DesktopWidget`，实现 `state()`，然后在 `WidgetManager` 的 `WidgetRegistry` 中注册类型及恢复工厂。公共右键、边缘缩放、状态保存和托盘行为可复用现有组件实现。
